# Skyy Engg Frontend v1.0

Responsive single-page frontend for Skyy Engg.

## Files
- `index.html` — page structure and content
- `styles.css` — complete responsive styling
- `script.js` — mobile navigation, reveal animations, AI workflow tabs and frontend form validation
- `assets/skyy-logo.png` — logo cropped from the supplied poster

## Run locally
Open `index.html` directly in a browser, or serve this folder with any simple static server.

## Backend integration points
The contact form uses the id `project-form`. In the backend phase, replace the demo form-submit handler in `script.js` with a POST request to your API or server endpoint.

Suggested next backend modules:
1. Enquiry submission API
2. Admin login and enquiry dashboard
3. Email/WhatsApp notifications
4. Project status tracking
5. File upload for datasets/documents
6. Database and security validation
